# Loan Approval Risk Analytics & Decision Insights

A data analytics project focused on understanding borrower risk patterns and loan approval behaviour using financial, demographic, and credit-related variables through R-based exploratory data analysis and visualisation.

## Main Focus

- Explore borrower profiles linked to loan approval
- Compare approved vs not-approved applicants
- Visualise credit score, income, age, debt, and account balance patterns
- Identify financial risk indicators for decision-making

## Tools Used

- R
- RStudio
- ggplot2
- CSV data processing
- Exploratory Data Analysis
- Business Analytics
- Data Visualisation

## Key Analysis Areas

- Age vs loan approval
- Monthly income vs loan approval
- Credit score vs loan approval
- Credit utilisation
- Open credit lines
- Debt-to-income ratio
- Payment history
- Checking account balance

## Business Value

The analysis helps explain which borrower characteristics are associated with loan approval outcomes and supports better risk-based lending decisions.
