# Loan Approval Risk Analytics & Decision Insights

This project explores loan approval behaviour using borrower financial, demographic, and credit-risk variables. The aim was to identify patterns that separate approved and not-approved loan applicants and translate the findings into business-friendly lending insights.

## Business Problem

Financial institutions need to understand which borrower characteristics are associated with loan approval outcomes. This analysis focuses on identifying useful risk indicators that can support credit assessment, lending policy review, and customer segmentation.

## Project Overview

The project uses R-based exploratory data analysis and visualisation to compare approved and not-approved applicants across income, age, credit score, account balance, credit behaviour, and repayment-related variables.

## Business Insights

- Approved applicants generally show stronger financial profiles across income and account balance indicators.
- Credit-related behaviour such as payment history, credit utilisation, and debt-to-income ratio provides useful signals for loan decision analysis.
- Visual comparison of approved vs not-approved groups helps communicate lending risk patterns to non-technical stakeholders.
